# Attribution

`Window Possum` is a custom Codex Pet created by Tristan Zhang with Codex.

The pet is inspired by the recent Chinese internet “背手负鼠” meme format: a possum standing in side profile with its hands clasped behind its back, often used for deadpan workplace and low-energy self-mockery.

The original meme/reference images are not redistributed in this repository. This repository only includes the generated Codex Pet package and preview assets.

The optional Chinese speech pack is original text written for this repository. It is inspired by recent Chinese internet workplace slang and self-mocking meme contexts, but it does not redistribute full third-party meme images or copied meme text.
